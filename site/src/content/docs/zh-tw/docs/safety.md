K-Browser 的出發點只有一個:agent 操作你已登入的瀏覽器時，必須容易看、容易停，而且跑不出它該在的範圍。

## 分頁歸屬

每個分頁屬於開它的 client,它開出來的彈出視窗也是。其他東西 client 都列不出、讀不到、動不了：你的分頁不行，別的 agent 的分頁也不行。每家 agent 有自己的 token,橋接永遠知道是誰在要求。

## 不搶焦點

agent 的分頁開在獨立的 K-Browser 視窗，這個視窗永遠不會被拉到前面。輸入直接送進頁面，不會搶走你的鍵盤，agent 做事時你可以繼續工作。

## 真的輸入，按之前再確認

點擊和打字走 Chrome 的輸入管線，跟人操作一樣。每次按下去之前,K-Browser 會確認目標還是 agent 原本要的那個元素。頁面在底下變了的話，它會停下來，不會點到別的東西，並回報做到哪一步。

## 封鎖網站類別

安裝時選擇 agent 不能用的類別:

| 類別 | 範圍 |
|---|---|
| `banking` | 網路銀行 |
| `payments` | 支付服務 |
| `email` | 電子郵件 |
| `government` | 政府網站 |
| `crypto` | 加密貨幣交易所 |
| `passwords` | 密碼管理器 |

每個 agent 可以封鎖不同類別，之後也能在側邊面板改。分頁一進到被封鎖的網站，只會回 `blocked_origin`;畫面上有被封鎖網站的框架時，截圖會被拒絕。

## 頁面文字只是資料

從頁面拿到的內容都包在 `<untrusted-page-content>` 裡,agent 分得出那不是你的指令。密碼欄位永遠不讀;網路紀錄裡的 token、卡號等會遮掉。

## 交給你處理

要登入、輸入驗證碼或做決定時,agent 會把分頁交給你。擴充的彈出視窗會出現「**顯示**」和「**交還**」;你交還之前，那個分頁上的每個工具都只回 `handed_off`。K-Browser 不會自己把分頁帶到前面。

## 看得到、隨時撤銷

側邊面板即時列出每個 agent 的分頁和動作。在這裡撤銷某個 agent,它的權限立刻結束。活動紀錄也可以寫到磁碟。

## 高風險工具預設關閉

`eval` 會在頁面裡執行 JavaScript(在隔離環境，但仍然能改動頁面)。要你對特定 client 打開才能用。截圖也可以對個別 client 關掉。

## 它不保證的事

遮罩是規則式的，擋不住所有個資。網站封鎖和頁面內容包裝可以降低風險，但不代表可以把 agent 放到你不信任它去的網站。
